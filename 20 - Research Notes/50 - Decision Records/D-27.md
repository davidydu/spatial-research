## Decision and authority

The current direction is a **pure Python rewrite of Spatial**, including its semantic compiler. Research the Python programming model first, then investigate HLS lowering, and review the design before compiler implementation.

Authority is David's report of the professor discussion on 30 September 2026 and David's subsequent instruction to follow the same research-before-implementation approach used for the Rust work. David also clarified the planning assumption of abundant capable coding agents and necessary team skills. This record does not claim an independently obtained professor approval of any detailed architecture.

## Scope

This supersedes the Rust-core recommendation linked from [[D-26-final-architecture]]. Preserve [[D-26]] and its experiments, hypotheses, thresholds, and historical conclusions. The new requirement changes the project direction; it does not change old measurements retroactively.

The public Python API, source-capture/builder choice, exact semantic policies, internal representation, simulator design, dependencies, and HLS strategy remain open. A Rust semantic core is not part of the new target. Ordinary Python runtime and future vendor-tool dependencies do not by themselves change the compiler's implementation language.

## Supporting research

[[2026-09-30-pure-python-feasibility]] concludes that Python can implement the necessary compiler algorithms. [[2026-09-30-pure-python-programming-model]] gives the first illustrative source form. These support feasibility and exploration, not a completed implementation or a finalized language contract.

The prior Rust proposal favored existing implementation assets and native execution headroom. Those remain historical facts and tradeoffs; they do not override the new requirement. Actual compiler/simulator performance must be evaluated against explicit workload and latency targets when an implementation exists.

## Consequences

- Maintain the new work under [[00 - Python Rewrite Index]], following [[01 - Python Research Plan]].
- Use original Spatial sources and earlier research as evidence; distinguish inherited Rust redesign policies from original language behavior.
- Use Codex-only delegation, with bounded parallel studies and independent checks of decisive claims.
- Keep detailed choices in the shared decision-record sequence. This record approves a direction, not the current source-capture sketch or a complete compiler implementation.
- Keep research documents and the website consistent. Existing history stays in place.
