# Advanced State and Communication Protocols

## Result and evidence boundary

This closes the architecture-level protocol questions listed by [[PY-R003 - Control Memory and Effects]]. The recommendation is an untimed event semantics with resumable communicating tasks, explicit resource arbitration, storage generations and published versions, and a separate scheduled profile. Each family below has a proposed default transition contract. Implementing that contract can be staged; its meaning must not be invented by a later HLS emitter or narrowed to the initial example corpus.

**Authority.** Original facts refer to `spatial@e7a8f2f7f776dd0c5ac7fc03f16b3ed4d97021f0`; short-SHA citations identify that revision. The checkout was clean at that revision when inspected. Source bodies and their cited ranges were inspected, and citation bounds are checked against pinned `git show` contents. The original [[80 - Streaming]] and [[40 - Memory Semantics]] are reading maps, including their explicit Scalagen/RTL differences; their Rust/HLS recommendations are historical evidence, not Python policy. [[PY-R002 - Numeric and Reduction Semantics]] supplies typed Bits and pure combining rules. [[PY-R004 - Capture Composition and Diagnostics]] supplies ordinary assignment RHS-before-target, augmented assignment target-once, and common source/builder effect order.

**Evidence class.** “Original” below means inspected source, not executed Scala or measured hardware. “Proposed” means the intended Python contract, not adopted specification or implemented support. Acceptance outcomes are calculated from that contract. No original application, RTL test, Python Spatial compiler, or HLS tool was run for this note. The bounded source review establishes important divergences; it does not certify every legacy target or its execution traces.

## One runnable semantic model

All rules in this section are **proposed**. An ordered kernel can produce one result and trace; a communicating graph generally denotes a set of allowed traces. Task arrival order is not determined by absent clock information. Deterministic arbitration means a unique choice *given the contender snapshot and arbiter state*, not a unique whole-program output regardless of arrival timing. Shared array/register races are rejected unless ownership, happens-before edges, published versions, or critical sections establish the intended order. Explicit channel arbiters resolve channel contention without pretending whole-task sequential replay models it.

This freedom applies only to task concurrency explicitly admitted by the source protocol. It does not weaken a contribution controller's ordered exactly-once effect evaluation from R002/R003: logical iterations and active lanes consuming the same FIFO must retain the declared iteration/lane order. A requested parallel contribution schedule must implement that order through dependencies/ordered endpoints or be rejected as an unsupported/conflicting schedule. Pure combining reassociation never makes contribution dequeues nondeterministic.

| Semantic object | Required fields and invariant |
|---|---|
| Task instance | Stable task/activation IDs, region and continuation/PC, captured operands, local object lifetimes, parent/join relation, outstanding requests, stop/cancel state. Suspension never re-enters completed statements. |
| Channel/stack | Backing ID and generation, typed token sequence, logical capacity in tokens, endpoint roles, close state, batch policy, arbiter descriptor/state. Capacity is semantic; physical banking is later. |
| Request | ID, requester, source span, dependencies, captured payload/address/mask, requested token count and resource generations. Evaluating operands and waiting for their operation are separate steps. |
| Grant/commit | Chosen contender snapshot, accepted request IDs, pre/post resource versions, consumed/produced token IDs, visibility/publication event. A grant reserved but not committed cannot appear as a dequeue. |
| Storage/version | Backing/generation, logical shape and view map, initialized-cell map, declared lifetime/reset image, ownership or publication lease. Physical duplicates do not create independent logical values. |
| Environment | Named endpoints, typed input/ready/close events, allocation/blackbox responses, replay order, declared fairness/progress assumptions. An absent response is not fabricated. |
| Trace | Task and activation, logical iteration/lane, source span, request/grant/commit, branch, token/value bits, backing/generation/version, and fault/cancel cause; causal predecessor IDs preserve a partial order. |

The simulator repeatedly advances a runnable task through a finite segment to its next effect/request or control boundary, resolves enabled resource transitions, and resumes the corresponding continuation. It records scheduling and arbitration decisions for replay. A canonical scheduler orders equally eligible task IDs for reproducibility; that order is **one witness**, not an extra source ordering guarantee. Bounded exploration may test other allowed schedules. Matching one witness does not establish confluence, deadlock freedom, or concurrent hardware refinement.

An abstract transition epoch groups actions only where an explicit batch or protocol arbitration requires a common prestate. It is not a clock cycle. Independent events may commute. The scheduled profile adds clock/reset domains, operation latency, issue intervals, handshake sampling, and any precise cancellation cutoff; it must refine the semantic graph rather than supply missing ownership or token rules.

| Outcome | Proposed rule |
|---|---|
| Disabled | No resource request/commit. An enclosing disabled region evaluates no enclosed operands. Already completed operand effects outside that region remain completed. Inactive vector positions are masked values, never usable fabricated data. |
| Ready | Atomic operation is feasible; commit its declared state change exactly once. |
| Blocked | Task/channel mode waits with captured operands and continuation intact. Ordered local FIFO/LIFO operations instead fault on underflow/overflow, as specified in R003. |
| Waiting environment | No internal transition can run and a concrete dependency path reaches a permitted enabling environment event. Return a resumable wait record. An unrelated open endpoint is insufficient; unknown enabling dependencies produce QuiescentUnknown. Empty does not mean closed. |
| End | Explicitly closed input has drained its accepted tokens. Tagged receive returns End; a plain value receive faults with EndOfStream. Output close follows outstanding-send completion. |
| Deadlock | No enabled internal transition and no permitted environment event can enable a blocked task. Return the wait-for graph and relevant queue/lock/version states. A timeout alone is not proof of deadlock. |
| Budget exhausted | A runnable or externally waiting nonterminated graph reaches a supplied execution budget. Preserve resumable state; do not report successful termination or semantic deadlock. |
| Fault | Halt successful result publication, preserve prior committed effects and trace, abandon only reversible/unissued private requests, retain every issued external obligation, then perform declared protocol cleanup/drain. No automatic rollback. |

Weak fairness is the default task scheduling assumption: a continuously runnable task eventually runs. Arbiter fairness is specified per resource below; fixed priority does not gain an unstated fairness guarantee. A scheduled backend must disclose any environment progress precondition needed for completion. A simulator cannot manufacture progress from that precondition.

## FIFO, LIFO, vector masks, and selection

**Original.** Scalar and vector FIFO operations carry enables, and `conflictable` explicitly permits an unsafe configuration in which simultaneous enqueues can drop one. Scalagen uses an elastic Queue, loops enabled dequeue lanes in index order, returns invalid for missing data, and does not enforce capacity on enqueue. LIFO uses an elastic Stack with analogous lane loops. (`spatial@e7a8f2f:src/spatial/lang/FIFO.scala:31-78`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenFIFO.scala:18-44`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenLIFO.scala:18-44`.)

**Original.** FIFO hardware compacts enabled lanes and updates occupancy by counts of enabled writes minus enabled reads. Its empty/full signals are thresholds relative to the widest configured reader/writer, not necessarily mathematical occupancy zero/capacity. LIFO hardware instead uses maximum push/pop group widths and OR-reduced enables; the source marks its parallel template as old style. Equal-width vector reads expose banks in ascending order, which does not establish sequential scalar-pop order. (`spatial@e7a8f2f:fringe/src/fringe/templates/memory/MemPrimitives.scala:380-432`; `spatial@e7a8f2f:fringe/src/fringe/templates/counters/Counter.scala:170-183`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MemPrimitives.scala:459-499`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MemPrimitives.scala:514-520`.)

**Proposed default transitions.** Let capacity be C, occupancy q, active dequeue/pop count m, and active enqueue/push count n. Capacity is a positive static or validated runtime descriptor; an operation requesting more than C tokens is permanently infeasible and faults/rejects rather than waiting forever.

| Operation or boundary | Exact rule |
|---|---|
| FIFO vector enqueue | Compact active lanes in ascending lane order and append that ordered list. All active lanes commit together or none do. Feasible when q+n<=C. |
| FIFO vector dequeue | Assign the first m old tokens to active lanes in ascending lane order, remove that prefix atomically. Feasible when m<=q. Disabled lanes consume nothing. |
| LIFO vector push/pop | Append active push lanes in ascending order to bottom-to-top storage; last appended is newest. Pop active lanes in ascending order from newest to oldest. Vector pop is scalar-pop order, deliberately distinct from a legacy equal-bank vector read. |
| Simultaneous accepted dequeue and enqueue batch | Read/pop from the common old state; require m<=q and q-m+n<=C; then remove old tokens and append pushes. Full storage can reuse slots freed by this accepted batch. Empty storage has no same-epoch bypass: new pushes cannot satisfy its pop. |
| Independent pending push/pop | Arbitrate feasible requests; a push to empty may commit before a previously blocked pop subsequently becomes ready. This is two transitions, not the simultaneous-batch bypass rule. |
| Observation | `empty=(q==0)`, `full=(q==C)`, `numel=q`. `can_read(m)` and `can_write(n)` expose width readiness separately. Almost-empty/full require an explicit threshold; scalar default threshold is one. Observations have a version and reserve nothing. |
| Peek | Nonconsuming read of current head/top. Ordered empty peek faults; task peek waits. Later mutations invalidate a cached observation. |
| Multiple ports | Endpoint contention requires an arbiter. The 3 October proposed default uses stateful round robin in stable endpoint-ID order with one shared admission cursor and one winning atomic request per resource epoch. A read/write batch is one explicitly declared request, never an opportunistic merge of independent requests. Losing requests persist. No silent loss and no dependence on source-file line hashes. A differently named fair arbiter is not automatically an equivalent implementation. |

Queue capacity is not a reason to split an atomic vector request into a successful prefix and an invalid suffix. A producer waiting to send two tokens into capacity one must receive a permanent-capacity diagnostic, even if a consumer could receive individual tokens. Explicit streaming scalar sends are a different legal operation. An enabled all-false mask is a no-op with no resource observation or arbiter pointer update.

**Original selection.** `priorityDeq` chooses the first eligible nonempty FIFO and relies on codegen to add the selected FIFO's own nonempty guard. The conditional overload combines occupancy and caller conditions. `roundRobinDeq(fifos,ens,iter)` is caller-indexed rotation: priorities are `(iter+index)%N`, and the minimum eligible priority wins. It contains no retained next-winner pointer. (`spatial@e7a8f2f:src/spatial/lang/api/PriorityDeqAPI.scala:10-22`; `spatial@e7a8f2f:src/spatial/lang/api/PriorityDeqAPI.scala:25-51`; `spatial@e7a8f2f:src/spatial/lang/api/PriorityDeqAPI.scala:55-104`.)

| Proposed selector | Transition |
|---|---|
| Fixed priority | Evaluate supplied conditions once in source order, capture their values, then snapshot candidate occupancy at grant time. Choose lowest listed eligible index; consume exactly one token from only that queue. If every captured condition is false, raise NoEnabledCandidate immediately after condition capture, before queue observation or wait registration; no pointer changes. With at least one true condition, enabled queues all empty waits in task mode or faults in ordered mode. Priority starvation is possible and explicit. |
| Caller-index rotation | N>=1 and count/enable lengths match. Capture iter once; priorities are mathematical nonnegative modulo of `(iter+i)` by N. Choose minimum eligible priority. N=1 works. This preserves the original rotation convention for nonnegative ordinary cases without importing signed modulo accidents from R002. |
| Stateful round robin | Store pointer p, initially 0. Search eligible candidates cyclically starting at p. On successful consumption of candidate j, set p=(j+1)%N. No eligible candidate leaves p unchanged. A continuously eligible candidate is selected within N successful grants. |

The all-false-condition fault applies to all three consuming queue selectors. It differs from an all-false vector mask, which returns no valid lane and performs no resource action. An enclosing disabled region evaluates no conditions and creates neither request nor fault. [[PY-R018 - Protocol Policy Refinement]] records this proposed refinement, its alternatives and boundary cases.

Selectors are one compound observation-and-consume action. Conditions cannot be repeatedly reevaluated while blocked; changes require an explicit retry/recheck region. Queue readiness is refreshed at grant time. One cannot separately peek every queue and later consume the winner without reserving/validating the same selection snapshot. Scheduled implementations must preserve selector effects, compacted lane order, atomicity, capacity, and the no-bypass contract; matching physical FIFO threshold signals to mathematical status requires adapters. The original LIFO group template is not sufficient evidence for those guarantees.

Competing compound selectors also participate in the selected queue's endpoint arbitration: reserve/consume that token within the same grant, and never grant two requests the same old token. A losing selector has no dequeue and no pointer advance. A batch groups only explicitly related requests; the runtime cannot combine arbitrary future operations into a batch to make a blocked program progress.

## Locks: exclusion, release, and visibility

**Original.** `Lock.lock(elements*)` produces a LockWithKeys allocation; memory operations optionally carry that descriptor. There is no explicit acquire/release node in the inspected lock node family. PIR emits LockOnKeys and attaches it to LockRead/LockWrite, requiring one key per emitted descriptor. The SimpleLock fixture pairs a read and write using one descriptor, but a paired source use does not establish when the backend releases it. (`spatial@e7a8f2f:src/spatial/lang/LockMem.scala:157-181`; `spatial@e7a8f2f:src/spatial/node/LockMem.scala:19-38`; `spatial@e7a8f2f:src/spatial/node/LockMem.scala:141-147`; `spatial@e7a8f2f:src/spatial/codegen/pirgen/PIRGenLock.scala:11-45`; `spatial@e7a8f2f:test/spatial/tests/feature/control/SimpleLock.scala:21-33`.)

The searched Scala and Chisel generator families do not expose corresponding lock handlers; this is a search observation, not a claim that no external PIR runtime implements locks. Python cannot infer a verified lock lifetime by treating that backend gap as a memory effect. The intended redesign is an explicit keyed critical-section region.

| Proposed lock state/operation | Rule |
|---|---|
| Descriptor | Lock identity, typed finite Bits key equality, logical live-key capacity, held-key→task/activation map, stable pending requests, stateful round-robin admission pointer. Equality is normalized packed Bits equality, not a floating numeric comparison or hash collision. |
| Acquire(keys) | Evaluate/capture keys once, deduplicate equal keys, canonicalize by lock-ID/type/bits order. Acquire the whole requested set atomically when all keys are unheld and capacity permits. More distinct keys than capacity is a permanent fault. Otherwise wait; no partial ownership. |
| Critical section | Nonreentrant owner capability attaches to accesses of a declared protected backing/address domain. Aliases retain the same domain. Every competing access must carry a compatible acquired capability or be proved outside concurrent activation. A lock key with no proven address-domain mapping does not prove memory safety. |
| Nested acquire | Permit only strictly increasing canonical lock/key order; reacquiring a held key or acquiring a lower key is a diagnostic/fault. This avoids acquisition-order cycles. Waiting on another channel while holding locks remains representable and may deadlock. |
| Visibility | Writes commit normally inside the section and the owner reads its writes. Release occurs only after its outstanding protected writes complete, publishes their memory version, and happens-before the next granted acquire of an intersecting key. No transaction rollback is implied. |
| Release | Normal region exit releases exactly its owned set. Releasing an unowned key faults. Scope escape of an ownership capability is rejected. On fault/cancel, prevent new protected actions, finish already issued noncancellable writes, then release in cleanup. |

An explicit atomic read-modify-write operation can be represented by the same ownership transition. Unlocked increments by two concurrent tasks are rejected; they are not accepted because the simulator happens to run one task first. Locks on distinct keys may proceed concurrently only if the protected address mapping establishes disjointness. Serializing keyed ownership is legal only with a progress/refinement proof as well as compatible concurrency/throughput constraints. For example, task A holds key A while waiting for a token that task B sends while holding disjoint key B. One global lock held until region exit would introduce deadlock and is invalid even without a throughput request. Serial request arbitration that releases its arbiter after granting independent permits is different from serializing entire critical regions. Report the achieved schedule and preserve requested overlap.

Legacy attached-descriptor syntax requires a validated import rewrite to a definite critical-section region. Ambiguous first/last-use inference, branch-dependent descriptor escape, and partial locking of a read-modify-write are diagnosed. This is an explicit compatibility boundary, not a removal of locks from the full language. Hardware capability checks concern exact exclusion, key capacity, admission policy, completion-before-release, and visibility; a pragma or memory port count alone proves none of them.

## MergeBuffer: sorted runs with explicit framing

**Original.** The API exposes per-way enqueue/bound, a Boolean init, and dequeue; allocation reports the fixed dimension 128. Hardware instantiates power-of-two ways and vector width, compares raw UInt payloads, tracks stream bounds with decrementing counters, and uses init to override comparisons toward one input. Its wrapper ORs lane enables into one vector-valid bit, so a partial mask is not transparently a token-compacting FIFO. (`spatial@e7a8f2f:src/spatial/lang/MergeBuffer.scala:16-32`; `spatial@e7a8f2f:src/spatial/node/MergeBuffer.scala:8-28`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MergeBuffer.scala:95-102`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MergeBuffer.scala:183-200`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MergeBuffer.scala:222-245`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MergeBuffer.scala:251-253`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MergeBuffer.scala:345-360`.)

PIR represents input data, bounds, and init through separate FIFOs. This is useful protocol evidence, not proof that the Scala generator supplies the same reference model. (`spatial@e7a8f2f:src/spatial/codegen/pirgen/PIRGenMergeBuffer.scala:25-66`.)

**Proposed.** Represent a merge actor with K>=1 ways, explicit per-way token capacity, frame ID, per-way expected/accepted/remaining counts, output delivered count, last accepted key, mode/comparator, input token FIFOs, output requests, and a private packer with capacity for one declared output vector. Bounds count active *tokens*, not vectors or cycles. Vector width does not change selected scalar value order, but its packing storage and atomic publication do affect progress and are represented explicitly. Begin a frame atomically with all nonnegative counts and mode. A default merge frame uses ascending typed order for integer/fixed keys; other Bits require a supplied pure total-order key/comparator. Floats require an explicit total order including NaNs and signed zeros, or reject NaN-bearing keys. The numeric descriptor comes from R002; raw-bit UInt order is a named optional legacy mode.

| Transition | Rule |
|---|---|
| Begin | Only when previous frame is finished and no input/output request remains. Set frame metadata; zero-count ways are exhausted immediately. Tokens cannot cross frame IDs. |
| Push way j | Compact active lanes in order, require within declared count/capacity and nondecreasing per-way keys, then atomically accept. Sortedness failure faults before accepting that vector. Waiting for capacity retains captured payload. |
| Merge output | Wait until every nonexhausted way has a head, so a missing head cannot hide a smaller value. Choose least key, then lowest way index for equal keys; preserve within-way order. Consume one token and decrement that way's remaining count. Exhausted ways never block. |
| Output vector | Capture its active mask/count m once and precheck remaining frame count >=m. Select and **commit input consumes one token at a time** into the private packer, freeing input capacity after each consume. Suspend with that captured prefix when the next head is unavailable. Once m tokens are staged, publish the whole output vector atomically and clear the packer. Cancellation cannot undo committed input consumes; abandoned staged tokens are traced. A request wider than declared packer capacity faults. |
| End/mismatch | Complete only after exactly sum(counts) output tokens are delivered and the packer/output request is empty; consuming the last input into a blocked packer is not completion. Early close of a way, excess tokens, illegal mode change, or beginning a frame with residual tokens faults. Temporary emptiness is a wait, not frame end. |
| Alternate concatenate mode | Exhaust way 0, then way 1, etc., preserving each run. This is explicitly named; `init(true)` is not silently interpreted as a reset or claimed to implement this policy on every original template. |

Default tie stability, typed ordering, arbitrary K, compacted masks, and framed tails are deliberate redesigns. A legacy import must make its raw-bit ordering/init mode and bounds units explicit; unclear legacy init/bound sequencing is rejected with those required repairs. Hardware must implement the chosen comparator, framing/counts, stable ties, readiness, and atomic output vectors. Sorting a batch after emitting it cannot repair selection that skipped a temporarily unavailable input.

## LineBuffer, RegFile, published versions, and state lifetime

**Original.** LineBuffer enqueues implicitly advance columns; simulation maintains bufferRow/readRow/write counters and swaps by stride. Its masked update calculates positions using lane index but advances its counter by the number of enabled lanes, which is not an uncomplicated active-lane compaction rule. Hardware requires a buffered LineBuffer, rotates rows at the N-buffer swap, and advances a parallel column counter under OR-reduced enables. The LineBufs fixture explicitly calls row 0 newest and the last row oldest. (`spatial@e7a8f2f:src/spatial/lang/LineBuffer.scala:16-38`; `spatial@e7a8f2f:emul/src/emul/LineBuffer.scala:14-59`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenMem.scala:145-148`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/NBuffers.scala:203-229`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/NBuffers.scala:246-275`; `spatial@e7a8f2f:test/spatial/tests/feature/memories/linebuf/LineBuffers.scala:24-32`.)

**Proposed LineBuffer.** Store an R×C logical newest-first window, R>=1 and C>=1, with per-cell initialization and a separate frame staging area containing S>=1 new rows. S may exceed R; publication retains the latest R rows. `begin_frame` captures the current version and creates uninitialized staging rows/cursors. Enqueue to staging row r, 0<=r<S, compacts active lanes in ascending order at that row's cursor; bounds are checked before the vector commits. Cursors are per row, so interleaving writes to different rows does not discard another row's position. The default requires exactly C accepted cells in every staging row. Partial rows require an explicit fill/padding image; there is no inferred zero or stale-cell reuse.

`publish_frame` is an atomic semantic event: reverse the incoming chronological rows so row S-1 is newest, prepend those S rows to the old window, retain the first R rows, and increment the window version. Old history remains uninitialized until enough frames or an explicit fill initialize it. Read addresses validate each logical axis and the selected version's initialization map. A sequential dense load into the line buffer includes begin/fill/publish; manually written `enqAt` requires an explicit publication boundary or a capture-time structured region that identifies one unambiguously. Compiler-inferred buffer rotation cannot secretly determine when the new window is visible.

For communicating pipelines, a publication endpoint carries version IDs and leases. Producer completion publishes a version exactly once; each declared consumer acquires its next publication in order and releases its lease on stage completion. A bounded version buffer defaults to two slots, with an explicit configurable positive slot count. A slot cannot be recycled while any consumer holds it or has an undelivered publication. Producer waits when all slots are live. Lease reads are immutable snapshots; ordinary “latest window” reads are available only in an ordered/exclusive region. Two logical versions can share physical cells only if the reuse proof preserves all live leases. The slot count is **semantic capacity**: changing it can change waits and deadlock. Extra physical storage must retain the specified admission credits; fewer physical slots need a proof of progress/refinement and cannot manufacture a new deadlock. A source-level slot-count change is a visible contract change unless its equivalence is proved. Physical N-buffer depth is consequently not a free replacement for semantic slot capacity.

**Original RegFile.** The API documents reset to initial values or zeros, and scalar/vector shifts. Simulation instead uses the generic invalid initialization/reset path when no image exists; shiftInVec reverses the input vector into increasing register coordinates. ShiftRegFile RTL defaults RegInit to zero, selects normal writes before shifts by PriorityMux, and N-buffered forms copy dump images at swap. The API's `.buffer` comment explicitly warns that pipelined and sequential results may differ. (`spatial@e7a8f2f:src/spatial/lang/RegFile.scala:27-31`; `spatial@e7a8f2f:src/spatial/lang/RegFile.scala:56-62`; `spatial@e7a8f2f:src/spatial/lang/RegFile.scala:131-144`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenRegFile.scala:14-31`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenMemories.scala:144-158`; `spatial@e7a8f2f:emul/src/emul/BankedMemory.scala:14-20`; `spatial@e7a8f2f:emul/src/emul/ShiftableMemory.scala:15-31`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MemPrimitives.scala:561-564`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/MemPrimitives.scala:630-648`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/NBuffers.scala:185-190`.)

**Proposed RegFile.** The default reset image is typed zero for every logical cell; an explicit full image replaces it. Construction and reset initialize all cells with that image. SRAM remains separately uninitialized by default. A shift along axis a of length D, using k<=D active input tokens in chronological lane order x0..x[k-1], atomically sets `new[j]=x[k-1-j]` for j<k and `new[j]=old[j-k]` otherwise, on the selected axis slice. k=0 is a no-op. Capture the old slice before writing it; shifts cannot be implemented as increasing-index in-place overwrite. Simultaneous overlapping ordinary writes/shifts have no implicit PriorityMux winner: order them, use an explicit atomic operation, or reject. Disjoint slices may commute. `.buffer` alone is a storage hint with a preservation obligation; stage-visible snapshots use the explicit publication/lease mechanism above.

| Proposed lifetime | Entry/reset/retention |
|---|---|
| Repeated-body local | Fresh logical Reg reset image, empty FIFO/LIFO, uninitialized scratch SRAM/LineBuffer history, initialized RegFile image on each body entry. Physical reuse cannot retain prior logical scratch state. |
| Enclosing loop local | Declared once before the loop; Reg/FIFO/RegFile state survives child iterations. No reset on a nested controller tick. |
| Task activation local | Declared in task initialization region; survives all suspension/resumption and repeat iterations of that activation. Cleared only when that activation ends/reset is requested. |
| Invocation local | Fresh when the kernel is called again, including after normal completion. The external memory object and host-provided data retain their separately declared lifetime. |
| Persistent/module state | Explicitly marked state, retained between invocations; initialized on module/session construction and explicit reset. Invocation cannot overlap another owner without declared synchronization. |

**Original lifetime limit.** Reg Scalagen emits object storage separately but calls initMem at declaration execution. Chisel memory reset is tied false when there are no resetters/breaker, not asserted at each parent advancement. Streamification FIFO initialization uses a RunOnceFIFO guard. These are distinct initialization mechanisms; they do not prove one universal fresh-allocation rule for original controllers or invocations. (`spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenReg.scala:14-17`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenMem.scala:201-207`; `spatial@e7a8f2f:src/spatial/transform/streamify/FIFOInitializer.scala:15-36`.)

Bare Reg[T] and RegFile[T,...] select the registered ZeroImage(T) when available: false for Bool, exact positive zero for numerical formats, zero for raw Bits, and recursively registered images for admitted aggregates. A descriptor without such an image requires an explicit supported reset or a diagnostic; the compiler never invents a valid all-zero tagged value. The checked allocation retains the selected reset bits. This proposed 3 October clarification does not initialize SRAM or seed FIFOReg availability, and does not make zero a reduction identity.

The Python lifetime table is the explicit redesign requested by R003, not a conclusion about every original reset path. HLS must preserve logical initialization and leases, including repeated invocations, not merely instantiate RegInit once. The matched discriminator remains: an outer Reg(0) incremented in three iterations yields 1,2,3; a body-local Reg(0) yields 1,1,1; an explicitly persistent outer Reg yields final 6 on a second invocation while invocation-local state yields final 3 again.

## General Bits FSM and unbounded execution

**Original.** FSM accepts general Bits state and stages separate condition/action/next lambdas. Scalagen initializes once, evaluates condition, executes action, executes next, assigns its result, and repeats. Chisel passes packed state through a width derived from the state type, emits all three blocks, and its controller updates state on iteration completion; reset includes `~enable`. Thus disabling an original FSM is not proven to be a state-retaining suspend. (`spatial@e7a8f2f:src/spatial/lang/control/FSM.scala:8-23`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenController.scala:224-235`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenController.scala:341-347`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenController.scala:469-484`; `spatial@e7a8f2f:fringe/src/fringe/templates/Controllers.scala:308-314`.)

**Proposed FSM states.** Represent `Initialize -> Test -> Action -> Next -> Test`, plus Blocked/Draining/Done/Fault. State has a fixed finite Bits layout: Bool, arbitrary-width fixed/float, vectors, and value structs are permitted; storage handles/endpoints are not embedded state values. Init evaluates once on activation. Test evaluates a pure/read-only condition from the current state and initialized observations; false goes Done with no Action or Next. Action receives the immutable old state and executes its ordered effects exactly once, suspending at channel/lock/transfer requests as needed. Next is pure/read-only, receives that same old state, and observes memory *after Action completion*. It computes the normalized next Bits value, which commits once. Test/Next cannot dequeue, write, allocate state, send, or invoke an effectful blackbox. Such legacy cases require moving effects into Action and explicitly carrying captured values; they are not silently duplicated by hardware combinational evaluation.

Enable false before activation means no activation. After activation, ordinary backpressure suspends without reinitializing state. Reset is an explicit separate transition. A next-state condition depending on an Action register write requires a completion/visibility dependency. Conditional action regions remain lazy. State can be a struct or packed float bit pattern without a hidden Int32 state-count limit; numerical operations retain R002's rules. A target may reject a specific packed-state/condition implementation as a capability limit, but the frontend cannot restrict the language to the old HLS FSM fixture's shape.

**Original forever.** Wildcard Stream uses a forever counter, but Scalagen continues while any detected FIFO/non-DRAM input is nonempty, or forever if no input is detected. It drains outer-stream children to exhaustion, explicitly acknowledging that this does not model feedback. (`spatial@e7a8f2f:src/spatial/lang/control/Control.scala:35-39`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenController.scala:14-41`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenController.scala:60-84`.)

**Proposed forever.** A repeat task starts another iteration until its explicit stop/close policy says otherwise. Empty open input is Waiting, never automatic successful termination. A finite environment closes an input explicitly after its last token. Tagged receive allows Action to handle End; `until_inputs_closed(named_endpoints)` is a separate structured helper whose completion requires all named inputs closed and drained and no outstanding action/transfer. Multiple-input alignment/zip can diagnose incomplete final tuples; priority merge can drain remaining sources. The helper cannot infer that behavior from “any queue has items.” A feedback channel has a declared seed token or an explicit seed-producing transition; an unseeded cycle whose tasks all receive first deadlocks. A source-only forever task remains runnable until stop/budget; finite simulation fuel is not a source termination rule.

## Implementation-readiness refinements, 2026-10-01

[[30 - State Simulator and HLS Blueprint]] supplies the closed transition/request records, region-to-continuation algorithm, unified resource/selector arbitration, fair scheduler, phase-specific cancellation and cleanup dependencies. A channel closes only after every declared producer endpoint closes and its accepted sends complete; End also requires drained committed tokens. Unknown enabling dependencies use resumable QuiescentUnknown, while Deadlock requires a finite closed wait certificate.

FIFOReg is a one-token elastic queue, initially/reset empty; stored reset bits are not an available token. `.value`/dequeue consumes, and assignment/enqueue produces. An explicit seed operation is separate. Ordered full/empty actions fault; communicating actions wait. This proposed policy resolves the original emulator/RTL ambiguity recorded in the blueprint. Masked vector results preserve lane validity through MaskedVec and require explicit filling before ordinary Bits use.

The default deterministic reference allocator uses explicit unsigned 64-bit byte-address values with base 0x1000, first-fit aligned address intervals, a separate packed-data quota, and fresh generation-bearing handles. Quota charge and portable byte-slot span differ for sub-byte elements. Raw addresses are observable values, never memory capabilities. Matched environment responses or a checked virtual-address mapping are required for reference/target comparison. Exact inputs, fault order and free/reuse rules are in the blueprint.

## Break, cancellation, drain, and reset

**Original.** Stream/Sequential API comments promise immediate break and resetting the breaker on completion. Scalagen warns its break takes effect at loop end; Chisel connects the break signal and breaker reset to controller done. Controller templates force active/done transitions on break. Those lines do not establish that all previously issued DMA writes or external sends have drained before done. (`spatial@e7a8f2f:src/spatial/lang/control/Control.scala:41-56`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenController.scala:75-93`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenController.scala:312-315`; `spatial@e7a8f2f:fringe/src/fringe/templates/Controllers.scala:106-117`; `spatial@e7a8f2f:fringe/src/fringe/templates/Controllers.scala:166-170`.)

**Proposed.** Make stop policy an explicit controller property, not an emitter accident. The default `breakWhen` is graceful **iteration-boundary stop**: test before admission and after each completed logical body; once observed true, admit no new iterations and finish already admitted bodies/children and their effects. It can wait forever on an open unresponsive environment; that is exposed as Waiting, not completed stop. A counted ordered controller admits only its current body; a concurrent controller records its admitted set explicitly.

Stop-sensitive controllers also carry a **semantic admission policy**, including admission window and fork/batch boundaries. The default counted Sequential/Pipe policy has one admitted logical iteration; pure speculation may compute ahead but cannot become a visible effect/admission. An explicit concurrent window W>=1 permits up to W admitted bodies, refilling only at declared completion/admission checkpoints after observing stop. A fork/join admission explicitly admits its child set together. Changing W, fork grouping, or the permitted overlap can change which effects have committed or must finish when stop is observed. Consequently `par`/II cannot be promised value-neutral for a stop-sensitive program if they alter admission policy: preserve the declared policy, request an explicit alternative, or reject the conflicting schedule. Semantic cache identity includes the admission policy; scheduled latency alone must not silently select it.

| Policy/transition | Commit and completion rule |
|---|---|
| Graceful stop | Complete admitted logical actions, pending sends, transfer commits, and acknowledgements; release locks/version leases; then report Stopped. No work from later iterations is admitted. |
| Explicit cancel | Deliver cancellation to the selected task subtree at the next semantic checkpoint, before a new request is issued. Withdraw only reversible/unissued requests; retain issued obligations even before visibility/acknowledgment; discard captured private values with an Abandon trace event. Completed dequeues/writes/sends remain completed. Cancel descendants and join their cleanup. |
| Issued external effect | An accepted send or issued DMA/blackbox transaction cannot be undone by source cancellation. Finish or invoke a separately declared external abort protocol; account for all resulting completions. No completion is synthesized or ignored. |
| Drain | Draining tasks may only finish issued protocol obligations and cleanup, not admit fresh user work. Parent completion waits for the obligation set to become empty. Failure to obtain external completion yields Waiting/DrainFailed, not Done. |
| Channels on cancellation | Close owned producer endpoints only after their accepted sends finish. Buffered committed tokens remain available to surviving consumers. Abandoned local-only channels are reclaimed with explicit discarded-token trace; shared buffers are not silently emptied. |
| Breaker reset | A legacy `breakWhen(Reg)` wrapper resets to its declared false/reset image only after drain, requiring exclusive breaker ownership. A shared/external stop signal is not automatically overwritten; use an owned activation stop token or explicit reset action. |
| Restart/reset | Start a new activation only after prior drain/cleanup or an explicit session-reset protocol. Reset cancels ownership and invalidates the old activation/generation; it does not pretend accepted external writes never occurred. |

Ordinary source `stop=true; dst[0]=7` in the currently admitted body still writes 7 under graceful break. Explicit cancel delivered between those statements prevents the second request; a write already committed remains. An “immediate at cycle t” contract belongs to a scheduled profile with declared sampling/issue cutoff, not this default reference model. The SimpleStreamPipeFlush fixture is evidence that stop and continually producing helper tasks coexist; importing it requires an explicit subtree-cancellation/drain boundary rather than naïvely waiting for every forever child to finish naturally. (`spatial@e7a8f2f:test/spatial/tests/feature/dynamic/StreamPipeFlush.scala:13-46`.)

## External streams and blackboxes

**Original.** StreamIn/StreamOut are directional value interfaces. StreamStruct is explicitly a bundle of independent decoupled fields: reading a field dequeues that field. Its FieldDeq node contains a TODO about the missing mutation effect. Verilog primitives assume fixed latency/II and no enable input; controller blackboxes instead declare per-field valid/ready, enable/reset/done and require an immediate Stream parent. Actual wrapper emission wires per-field handshakes and done. (`spatial@e7a8f2f:src/spatial/lang/StreamIn.scala:14-24`; `spatial@e7a8f2f:src/spatial/lang/StreamOut.scala:15-25`; `spatial@e7a8f2f:src/spatial/lang/StreamStruct.scala:7-35`; `spatial@e7a8f2f:src/spatial/node/StreamStruct.scala:12-20`; `spatial@e7a8f2f:src/spatial/lang/Blackbox.scala:64-95`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenBlackbox.scala:94-115`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenBlackbox.scala:147-163`.)

**Original divergence.** Scalagen stream input is a queued file/parser boundary and reads empty as invalid. Its support for vectors and structs does not make independent StreamStruct fields into one atomic record. AXI emission sets/filter defaults when the user supplies only a payload; full AXI payloads expose sideband fields. (`spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenStream.scala:23-39`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenStream.scala:84-97`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenStream.scala:81-114`.)

| Proposed family | Default reference protocol and representation |
|---|---|
| Stream of value structs | Each token is one immutable packed typed record, including sidebands declared in its type. Receive/send transfers the entire token exactly once. Direction/capacity/close and environment binding are endpoint properties. |
| Bundle of streams / StreamStruct | Named independent endpoints; each field read is a consume effect on that endpoint. Reading x twice consumes two x tokens and no y token. Zip consumes one token from each named field in declared field order, retaining a committed partial prefix across waits, then publishes one result record atomically. End/cancel never rolls back those consumes. A coherence adapter must explicitly check/match transaction/frame IDs when same-index pairing is insufficient. |
| External send | Capture token once, offer a stable request until environment acceptance, then commit once. Not-ready is wait. No second evaluation, token replacement, or duplicate send while pending. |
| External receive | Environment delivers a typed token to the named endpoint; receive consumes it once. Validate exact bit layout/sidebands. EOF/close is an explicit event, not all-zero payload or temporary lack of valid. |
| Spatial primitive | Typed pure function region when effect verification succeeds; otherwise an explicit effectful operation/actor with its contract. Original Unique annotation is not proof of purity. |
| Foreign primitive | Descriptor includes artifact identity, typed input/output layout, parameter values, numerical contract, reset/lifetime, purity/state effects, and a versioned reference-model ID or explicit replay-provider descriptor. Untimed pure calls return the specified value; stateful calls mutate their declared instance state exactly once. No stub zero output. |
| Foreign controller/transducer | Actor descriptor includes input/output fields, reference transition relation/model, initial state, acceptance/production order, done condition, capacity, cancellation/drain, and optional progress guarantees. Completion does not consume outputs twice or discard unaccepted outputs. |
| Missing reference behavior | Accept declaration as an external semantic dependency, but refuse a value-producing reference run without a model/recorded environment oracle. Hardware emission requires a validated adapter and descriptor. Neither simulation success nor hardware value parity can be claimed. |

The reference simulator calls only validated pure Python models or the explicit environment adapter; it does not execute arbitrary embedded HDL or host callbacks during source capture. An effectful foreign call cannot be CSE'd, duplicated, speculated into an inactive branch, or moved across reset. Fixed latency and pipeline factor are scheduled constraints only when supplied; no latency is invented for an untimed model. Stable ready/valid payloads, clock/reset conversion, bus sideband mapping, and throughput are adapter proof obligations. “Blackbox” is a language family with a contract, not a loophole around effect ownership.

Canonical IR contains model IDs, schema versions, implementation/code hashes, and declared transitive dependency hashes; it contains no live Python function or closure. A reviewed registry resolves these IDs outside the graph. Mutable state, environment responses, and randomness are explicit invocation inputs/resources, not ambient globals. Model registration is a trusted extension boundary requiring audit and independent conformance; it does not prove arbitrary host code pure. A changed dependency changes semantic identity; missing/mismatched models diagnose. Otherwise a model that reads a later host `gain` value could silently change cached simulation meaning.

## Dense/sparse transfers, repeated addresses, and dynamic DRAM

**Original.** DenseTransfer lowers into Stream command/data/ack controllers, limits upper-dimension parallelism and byte packing, and derives unaligned burst masks. SparseTransfer consumes address/local sources, rounds non-PIR requests up to sixteen, repeats last address/data for padding, and assumes acknowledgement counts. Scalagen processes sparse store commands in queue order and emits an ack after each; that establishes its loop order, not all hardware bus orders. (`spatial@e7a8f2f:src/spatial/node/DenseTransfer.scala:85-98`; `spatial@e7a8f2f:src/spatial/node/DenseTransfer.scala:163-185`; `spatial@e7a8f2f:src/spatial/node/DenseTransfer.scala:273-299`; `spatial@e7a8f2f:src/spatial/node/SparseTransfer.scala:59-76`; `spatial@e7a8f2f:src/spatial/node/SparseTransfer.scala:108-122`; `spatial@e7a8f2f:src/spatial/node/SparseTransfer.scala:148-167`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenDRAM.scala:78-84`.)

**Proposed common descriptor.** Transfer ID, endpoint backing/generations/views, direction, element type, captured logical extents/origins/strides, source kind (snapshot array or consuming stream), logical item order, address/data captures, outstanding issue/commit/ack IDs, ownership domains, completion and cancellation policy. Logical addresses/counts use checked shape integers, not silently wrapping accelerator arithmetic. All endpoint/count expressions evaluate once in their declared effect order; a transfer node has an explicit order and is not translated into ordinary assignment with an invented target-first evaluation. An enabled zero-size transfer performs no token consume, memory access, command, or ack wait.

| Proposed operation | Precise value/effect contract |
|---|---|
| Dense array→array | Row-major logical item order. Validate compatible extents/type and every logical address/initialized source cell, then snapshot all sources before destination writes. Write items in order. Overlap behaves like a source snapshot, not a forward overwrite loop. Transfer owns conflicting source/destination domains until completion; other tasks wait or are rejected for missing ownership. |
| Array gather | Snapshot the address list and origin, validate every address, then snapshot selected source values, including duplicate reads, before destination writes. Repeated addresses produce repeated values in list order. |
| Array scatter | Snapshot addresses and source data before writing. Write in list order; repeated destination address uses last logical item. Explicit atomic-combine scatter is a separate operation with R002's combining/order contract. `par` cannot select an accidental lane winner. |
| Stream/FIFO/LIFO transfer | Stream semantics, no whole-source snapshot. For each item capture an address token if needed, then a data token/read if needed, validate, issue, commit, and account for completion. Captures survive waits; no rereads/dequeues. FIFO order is oldest-first; LIFO order newest-first under the specified scalar-pop contract. |
| Streaming gather/scatter tails | Exactly requested logical item count; no padding token consumption. Invalid streamed address faults after its already completed consume; no destination effect for that item. Earlier committed items remain. Repeated streaming scatter addresses are serialized in logical item order. |
| Completion/visibility | Blocking transfer returns only after all logical destination commits and required external acknowledgements. Issue is not completion. Async transfer yields an ownership/event handle; join releases domains and makes completion visible. Reading a conflicting destination before join requires an explicit ordering relation. |
| Lowering padding | Physical extra beats cannot consume extra logical FIFO/address/data tokens, write out-of-range logical cells, or alter repeated-address outcomes. Guard/padding/private staging is an implementation detail. |

For array transfers, preflight failure occurs before any transfer destination write. Evaluation effects preceding the transfer remain, and a failed transfer is not rolled back history. Stream transfers cannot promise that preflight property for unknown future address tokens; they report the completed prefix. The transfer is semantically isolated against other accesses by its ownership domains, not necessarily one indivisible physical memory-bus transaction. Intra-transfer issue concurrency is allowed only if source snapshot and repeated-address ordering are preserved. Cancellation finishes already issued noncancellable transactions but stops unissued logical items; the trace exposes the resulting committed prefix plus unavoidable issued completions. An ordered blocking transfer is not interleaved with its caller's later statements.

**Original dynamic DRAM.** Rank-only DRAMAccelNew starts with zero dims; allocation/deallocation are enabled write effects. Chisel routes app allocation requests to a DRAMAllocator; its template chooses a request with PriorityEncoder and exposes allocation metadata influenced by request and heap response. Scalagen's inspected DRAM generator handles host allocations, reports isAlloc true and address zero, and does not establish the dynamic allocation lifecycle. (`spatial@e7a8f2f:src/spatial/node/DRAM.scala:13-31`; `spatial@e7a8f2f:src/spatial/codegen/chiselgen/ChiselGenDRAM.scala:26-66`; `spatial@e7a8f2f:fringe/src/fringe/templates/memory/DRAMAllocator.scala:61-88`; `spatial@e7a8f2f:src/spatial/codegen/scalagen/ScalaGenDRAM.scala:16-28`.)

| Proposed dynamic state | Transition |
|---|---|
| Unallocated | Rank/type known, no backing generation. Size/address access requiring a live allocation faults; is_allocated is false. |
| Allocate(dims) | Capture/check dimensions once, acquire exclusive owner, enter Allocating with request ID. Zero extents are legal empty allocations. An environment allocator may wait/fail; deterministic reference allocator uses a declared quota and abstract addresses, never host pointers. |
| Allocation completion | On success assign fresh backing/generation, checked shape/size, reset-image initialization, and abstract address, then enter Live. Default allocation image is typed zero, consistent with proposed host DRAM; explicit uninitialized allocation is a different declared policy. AllocationFailed leaves Unallocated. |
| Live accesses/views | Each view/request carries generation. Bounds/init/ownership checked before logical access. Abstract address values cannot grant authority over another allocation or be confused with host object addresses. |
| Reallocate/deallocate | Allocating while Live faults; resizing is an explicit joined replacement/copy operation. Deallocate requires exclusive owner and no outstanding transfer/lease; otherwise waits for those obligations. On completion invalidate the generation and all old views, enter Unallocated. |
| Reuse | A later allocation may reuse an abstract/physical address but receives a new generation. Old views fault StaleGeneration. Double deallocation faults; an explicit conditional `if is_allocated` is legal. |

Stored inert view descriptors may survive deallocation as invalid handles; they do not prevent it. Active transfer/ownership/read leases must drain first. A later stale use faults, or is diagnosed statically when provable; address reuse never revalidates the old descriptor.

External borrowed DRAM retains host/session lifetime; kernel reset does not deallocate the host buffer. Invocation-owned dynamic DRAM is freed only after drain/joins; explicitly persistent dynamic DRAM retains its live generation across invocations until released/reset under its declared lifecycle. Allocation admission defaults to stateful round robin among requesters, distinct from original fixed PriorityEncoder. Resource quota failure, nonresponse, and invalid dimensions are separate outcomes. Hardware obligations are response-based allocation completion, safe generation/use-after-free checks or proofs, nonoverlap with outstanding traffic, source snapshots/overlap handling, repeated-address serialization, and exact logical tails. No vendor facility is assumed to supply them.

This is a full intended protocol policy, not a promise that first implementation supports every family. Checked semantic IR must carry these state transitions, not encode everything as anonymous memory writes. The architecture study should retain task continuations, captured operands, semantic arbiter descriptors, environment identity, generation/version leases, and cancellation obligations in its semantic dialect; an implementation dialect adds actual banks/credits/ready-valid/cycles with a preservation relation. Generic “pure” traits are inappropriate for operations that may consume, wait, fault, acquire locks, or cancel.

Original-fidelity limits remain concrete: PIR lock runtime release/visibility is outside the inspected repository handlers; MergeBuffer init/framing corner cases and equal-bank LIFO masks need executed original tests if migration fidelity is requested; host/board reset and repeated invocation require a target-specific original contract; bus-level repeated-address order and in-flight break behavior require actual transactor/RTL traces. Those limitations do **not** leave the proposed Python meanings undefined. A legacy compatibility profile must pin a backend and import those contracts explicitly, or diagnose the mismatch. It cannot be advertised as one universal original-Spatial behavior.

Before implementation acceptance, execute the discriminators against the Python reference model and inspect the normalized source/builder graph; replay more than one allowed concurrent schedule where order is not fixed. Before HLS acceptance, compare protocol traces and invariants including full/empty simultaneous boundaries, partial masks, aliases, generation reuse, wait/close, fair selection, visibility, cancellation/drain, and all acknowledgements. Cycle counts/II and vendor resource claims require their own scheduled evidence. These rules feed the proposed state/protocol contract; adoption and executable support remain separate.
